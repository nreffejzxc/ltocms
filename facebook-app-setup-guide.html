🚨 Fix "App not active" Facebook Error

❌ Current Error:

"App not active - This app is not accessible right now and the app developer is aware of the issue."

This happens because your Facebook app is in Development mode and you're not added as a developer or test user.

🔧 Quick Fix Steps

Step 1: Access Facebook Developer Console

Click the button below to open Facebook Developers:

Open Facebook Developers

Make sure you're logged into Facebook with the account you want to use for testing.

Step 2: Find Your App

Look for your app with ID: 798034545888164

Can't see your app? This means you're not added as a developer. Contact the app owner to add you.

Step 3: Add Yourself as Developer (Most Important)

In your Facebook app:

  1. Go to "Roles" → "Roles"
  2. Click "Add People"
  3. Enter your Facebook email or username
  4. Select role: "Developer" or "Administrator"
  5. Click "Submit"

You must be added by an existing admin/developer of the app.

Step 4: Configure App Settings

Once you have access, verify these settings:

Basic Settings (Settings → Basic):

  • App Domains: localhost
  • Website Site URL: http://localhost:5000
  • App Mode: Development

Facebook Login Settings (Facebook Login → Settings):

  • Valid OAuth Redirect URIs:
  • http://localhost:5000/api/auth/facebook/callback
  • http://localhost:5173/auth/callback
  • Client OAuth Login: Yes
  • Web OAuth Login: Yes

Step 5: Test the Fix

After making the changes:

  1. Wait 2-3 minutes for Facebook to update
  2. Clear your browser cache
  3. Try the Facebook login again
Test Facebook Login

✅ Expected Result:

You should see the normal Facebook login page instead of "App not active" error.

After logging in, you'll be redirected back to your application.

🚨 Alternative Solutions

Option A: Add Test Users

If you can't be added as a developer:

  1. Go to "Roles" → "Test Users"
  2. Click "Add"
  3. Create a test user or add existing Facebook account
  4. Use that account for testing

Option B: Switch to Live Mode

⚠️ Not recommended for development

This requires Facebook app review and approval.

  1. Go to "Settings" → "Basic"
  2. Toggle "App Mode" to "Live"
  3. Submit for Facebook review (can take days/weeks)

🔍 Troubleshooting

Still Getting "App not active"?

  • Wrong Facebook Account: Make sure you're logged into Facebook with the account added as developer
  • Cache Issues: Clear browser cache and cookies
  • Time Delay: Wait 5-10 minutes after making changes
  • Incognito Mode: Try testing in private/incognito browser
  • App Restrictions: Check if your app has any policy violations

Backend Issues

If your backend is crashing, make sure:

  • MongoDB is connected properly
  • All environment variables are set
  • No syntax errors in your code

🎉 Success Checklist

You'll know it's working when:

  • ✅ No "App not active" error
  • ✅ Facebook login page appears normally
  • ✅ Successful redirect back to your app
  • ✅ User is logged in and can access dashboard
